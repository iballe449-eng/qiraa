# Qirāʾa · Lire le Coran

Application pour apprendre à lire l'arabe et le Coran en 4 semaines (22 leçons, exercices, alphabet, voix arabe, 4 sourates mot à mot).

## Mettre en ligne
1. Crée un dépôt **public** sur GitHub (par exemple `qiraa`).
2. **Add file → Upload files** : sélectionne les 9 fichiers, puis **Commit changes**.
3. **Settings → Pages** : *Deploy from a branch*, **main** / **(root)**, **Save**.
4. Adresse : `https://TON-NOM.github.io/qiraa/`

## Installer sur le téléphone
- Android (Chrome) : menu ⋮ → **Installer l'application**.
- iPhone (Safari) : **Partager → Sur l'écran d'accueil**.

## Voix arabe
L'app utilise la voix de synthèse du téléphone. Si aucune voix arabe n'est installée :
- Android : Paramètres → Système → Langues → Synthèse vocale → moteur Google → installer « Arabe ».
- iPhone : Réglages → Accessibilité → Contenu énoncé → Voix → Arabe.
